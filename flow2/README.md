# PlantMe · Flow 2.0

[Abrir a página no Figma](https://www.figma.com/design/l6fOEzCk3migCg7NOUlNRl/PlantMe-2.0?node-id=557-1607)

O Flow 2.0 reúne 32 telas editáveis de UI design em 375 × 667 pt (iPhone SE 2020), organizadas por acesso, primeira planta, rotina, conteúdo/comunidade e perfil. O mapa na primeira seção mostra a sequência principal. Há 151 conexões de protótipo; os CTAs principais têm destino.

Sistema visual aplicado: fundo creme, verde PlantMe nas ações, Nunito Black/ExtraBold para títulos e ações, Manrope para corpo, fotografias de plantas já usadas no projeto e Brotu em momentos contextuais. A barra de status é a instância iOS usada na página `ui design final`. Cards, textos, botões, imagens e navegação permanecem em camadas editáveis.

O fluxo de ativação é: splash → boas-vindas → criar conta ou entrar → experiência → interesses opcionais → adicionar planta → local e luz → frequências → revisão → plano criado e permissão de notificações → início. A permissão aparece após a criação do plano, com as informações da Jiboia e os cuidados ao fundo.

As telas de estatísticas exibem dados ilustrativos da usuária Anna para dar corpo à UI; as regras reais de contagem devem ser definidas na implementação do produto. Clima local continua opcional e não determina a rega sozinho.
