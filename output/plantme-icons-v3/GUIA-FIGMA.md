# Ícones PlantMe para Figma

Todos os 22 arquivos são SVG vetoriais de 24 × 24 px, com caminhos abertos e traços editáveis. Cada path usa cor explícita #214F38, largura 1,9 px (normal) ou 2,4 px (selecionado), extremidades e junções arredondadas. Não há PNG, círculos de seleção, fundos nem strokes convertidos em preenchimentos.

## Importar
Arraste os SVGs para a página do Figma ou use File > Place image. Selecione o ícone importado e, se necessário, entre no grupo até selecionar o(s) caminho(s). Edite Stroke para mudar cor e espessura. Use o campo de dimensões para mudar tamanho. Com Scale (K), Figma escala dimensões e traços juntos; se quiser mudar só o tamanho do desenho, redimensione e reajuste a espessura em Stroke.

Os arquivos `normal` e `selecionado` são estados visuais do mesmo símbolo. Crie componentes com variantes no Figma para organizar a biblioteca. Os quadros arredondados mostrados na prancha são apenas parte da apresentação e não fazem parte dos SVGs.
